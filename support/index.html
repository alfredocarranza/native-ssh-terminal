Native SSH Terminal Support

Native SSH Terminal connects directly to SSH servers you configure. Carranza Technologies does not provide or administer an SSH server account.

Trial, unlock, and restore

Download is free. Have your SSH server ready, then open Settings > Trial & Purchase Status and choose Start 7-day Trial. Confirm My SSH Server Is Ready — Start Trial and complete Apple's acquisition flow. Your seven days begin with the original verified Apple acquisition, not your first connection. After expiry, new SSH connections and reconnects require the optional $0.99 Permanent Unlock (U.S.), a separate one-time purchase. There is no subscription or automatic charge. Expiry itself does not interrupt an active session or erase hosts, keys, settings, or scrollback. For an existing purchase, use Restore Purchases with the same Apple Account; restoring or reinstalling does not restart the trial. If access needs verification, use Retry Verification and Offers or Restore Purchases rather than repurchasing to recover access. Contact alfredo@carranza.tech if the problem persists; never send passwords or private keys.

Before connecting

  • Confirm the server hostname or IP address, SSH port, and username.
  • Choose password authentication or create/import an Ed25519 key on the Keys tab.
  • For a private-network host, allow Local Network access when iOS asks.

Host-key warnings

On first connection, the app records the first key presented and displays its fingerprint. Verify that fingerprint with your server administrator; if it is unexpected, disconnect and clear trusted host keys in Settings. If a trusted key later changes, the app refuses the connection. Do not remove the old key until the new fingerprint has been independently confirmed.

Troubleshooting

  • Connection refused: verify the host, port, firewall, VPN, and that SSH is running.
  • Authentication failed: verify the username, password, or that the displayed Ed25519 public key is authorized on the server.
  • Private address unreachable: verify Wi-Fi/VPN routing and Local Network permission in iOS Settings.
  • Changed host key: compare both fingerprints with the server administrator before reconnecting.
